# Decision log

One entry per decision that someone could reasonably have made differently.
Newest at the bottom. Never edit an old entry's decision; add a new entry that supersedes it.

Template:

```markdown
## D-000 · YYYY-MM-DD · Short title
- Context: what forced a decision
- Options: A / B / C
- Decision: which one
- Evidence: eval numbers, benchmark, or link
- Revisit if: the condition that would change it
```
