# Build it yourself first

Each exercise is done by hand before using a library that does it for you.
Create the folder when you start the exercise.

| Folder | Week | Exercise |
|---|---|---|
| `01-gpt/` | 1 | Type along with Karpathy's “Let's build GPT” |
| `02-tokenizer-sampling/` | 1 | BPE tokenizer; temperature, top-k and top-p over raw logits |
| `03-tool-loop-raw-http/` | 2 | Tool-calling loop over raw HTTP, with backoff and a semaphore |
| `04-bm25-rrf/` | 3 | BM25, cosine top-k and reciprocal rank fusion in numpy |
| `05-llm-judge/` | 4 | A pass/fail judge and its agreement with hand labels |
| `06-react-agent/` | 5 | A ReAct loop in about 100 lines |
| `07-compaction/` | 6 | Context compaction with a planted-fact test |
| `08-tracing/` | 7 | Tracing by hand on the OpenTelemetry GenAI conventions |
| `09-lora/` | 9 | A LoRA layer in PyTorch |
